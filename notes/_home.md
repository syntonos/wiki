# Home

Welcome to the vault. This page is the **homepage**: it is not a note, so it never appears in the graph.

## How it is organized
- **General** notes live at the top level of the `notes/` folder.
- Each **folder** is a topic. Folders can nest as deep as you like.
- Notes connect through `[[wikilinks]]`; open the **Graph** tab to see the map.
- The **Index** below is generated automatically from every note.

## Using the site
Instructions and feature demos live in the `Demo` folder (open it in the sidebar). To hide that folder once you no longer need it, set `SHOW_DEMO` to `false` at the top of `src/App.jsx`.

Edit this page in `notes/_home.md`. Anything above the Index is yours to change.
